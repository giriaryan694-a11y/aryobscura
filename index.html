Target

pick the platform, then the script type

Windows

Binary formats (.lnk, .scr, .exe) can't be text-obfuscated directly — the LNK target emits a generator script that builds the shortcut with an encoded target.

Linux

.desktop is a launcher format — obfuscation wraps the Exec= command in a decode-on-run shell call. "that shortcut file" (.desktop) is the Linux counterpart of .lnk.
